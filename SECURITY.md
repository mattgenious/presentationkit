# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately to the repository owner instead of opening a public issue with exploit details.

Include:

- Affected version or commit.
- Steps to reproduce.
- Impact and any known workaround.

## Sensitive content policy

PresentationKit is intended to be brand-neutral and safe to publish. Do not commit:

- Credentials, API keys, tokens, or private environment files.
- Proprietary brand assets, templates, fonts, screenshots, or internal-only visual rules.
- Customer data, private metrics, or confidential deck output.

Use `brandPack` metadata to point to authorized external brand companions instead of embedding private brand material in this repository.
